# MERN E-Commerce Demo

Full-stack e-commerce demo built with **MongoDB, Express, React, Node.js**. Includes user auth (JWT), product/catalog pages, cart/checkout, orders, and PayPal integration.

## ✨ Features
- User auth (register/login) with JWT + password hashing
- Product listing, details, search/filter (if implemented)
- Cart + checkout flow
- Orders (create/view)
- Admin basics (add/edit products) *(if implemented)*
- Payments via PayPal (client ID from env)
- Seed script for quick demo data

## 🧰 Tech Stack
- **Frontend:** React, React Router, (Redux/Context if used)
- **Backend:** Node.js, Express
- **Database:** MongoDB / MongoDB Atlas
- **Auth:** JWT, bcrypt
- **Payments:** PayPal
- **Tooling:** npm/yarn, nodemon (dev)
